\section*{Compute, Funding and Authorship}
All experiments were run on free Kaggle GPU sessions: two NVIDIA T4 GPUs per kernel
(one data shard per GPU), with Kaggle's 12-hour session cap. No institutional compute,
funding or supervision was involved. The study was designed, run and written by a single
author. The code, notebooks and exported logs are on GitHub. This paper is archived on
Zenodo at \url{https://doi.org/10.5281/zenodo.23766104}.
